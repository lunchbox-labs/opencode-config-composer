# Configuration contract

Root: `$schema`, `defaultProfile`, `model`, `small_model`, `models`, `groups`, `agent`, `command`, `profiles`.

Groups: a map keyed by group name, with `{ description?, agent? }` values. Empty groups are valid for profile-only settings. Profiles: a map of `{ description?, model?, small_model?, models?, groups?: { [groupName]: { agent? } }, agent?, command? }`. All references and targets are exact names; structural errors and unknown names are invalid even in inactive profiles. Command settings use the root or profile's named `command` map.

Each native agent owns `groups: string[]`, in Markdown frontmatter or at `agent.<name>.groups` in native JSON, including built-ins. The array contains unique, nonempty exact group names; unknown groups fail composition. Missing membership means none, and `[]` explicitly clears it. The latest authored Markdown declaration replaces the whole previous declaration and takes priority over native JSON; an omitted later Markdown field leaves the previous declaration intact. Only the top-level native JSON field supplies JSON membership. `options.groups` does not supply membership. Composer removes its `groups` metadata before native agent use; it is not a provider option. Definition-map insertion order never reorders agent membership.

Agent patch: `model` or `modelRef` (mutually exclusive), `variant`, `temperature`, `top_p`, `options`, `mode`, `permission`. Command patch: `agent`, `model`, `subtask`. No null unset operations in the document. Persisted null selection means None; missing selection follows `defaultProfile`.

Root and profile `models` are maps of exact alias names to `{ model: "provider/model", variant?: string }`. Names must be nonempty and contain no NUL. Bindings cannot chain or contain other settings. Resolve each reference against root bindings with whole selected-profile binding replacement. A binding without `variant` writes the native default (`variant: ""`), clearing an earlier variant; an explicit referencing patch `variant` wins. Later groups or named patches can override either field, and frontmatter is final. Ordinary concrete `model` patches retain independent variant inheritance.

`modelRef` exists only in Composer group and named agent patches, including profile patches. It is resolved before native materialization and never becomes a native field or provider option. Root bindings apply in Shared only. A name defined only in profiles contributes neither model nor variant in Shared only, even when the reference has an explicit variant; unrelated patch fields still apply. In a selected profile, every consumed reference needs a binding in that profile or at root; a binding in another profile is insufficient. Unknown alias names fail validation everywhere. Errors identify the reference pointer and missing alias/profile. Unused group references do not require selected-profile bindings.

Precedence: supplied native fields → each agent-owned group with its selected profile patch, in membership order → root named patches → profile named patches → actual authored agent frontmatter. A later group wins even over an earlier group's profile patch. Authored options/permission are whole-field pins; empty values are explicit. Later Markdown sources replace each authored whole field. Composer permission objects replace and reorder touched exact tool blocks; scalar actions replace the policy. Native bodies are never edited.

Authored frontmatter is final even over a conflicting later native JSON value. `/view-configs` shows the authored source and blocked Composer candidate where attribution matches the loaded contribution. Same-batch duplicate native identities and unsupported frontmatter engines or metadata stop composition with a source diagnostic. Correct the native input and restart the OpenCode server process. Failed bootstrap can prevent profile switching; inspection still shows available native values without claiming complete Composer attribution. Normalized host defaults cannot substitute for exact authored authority.

One source defaults to the configuration directory's `config-composer.jsonc`; optional `configFile` is absolute or relative to that directory. Missing implicit source is empty; missing explicit or invalid definitions remain startup errors until server restart. No source stacking. The loaded document, options, source and external selection locator are captured once per directory/worktree in the server process. File edits, deletion and source retargeting do not change that capture.

`/profiles` directly offers Follow configured default, Shared only and loaded named profiles, with preview and one Apply confirmation. The selection is persisted separately per canonical source/worktree; it never changes JSONC definitions. `/view-configs` is read-only inspection of loaded definitions, membership, origins, agent frontmatter pins, blocked Composer values and effective native values. Pending saved choices remain in `/profiles`. Inspection does not read current definition/native files. Restart the OpenCode server process after file edits; reconnecting the TUI does not reset the capture.

Applying uses the idle native instance lifecycle. Directly observed native JSON, agent metadata/body or command edits block profile switching with a restart instruction. These observations are not a complete dependency graph of native includes, environment or other plugins. Composer does not replay native bodies or provider/session configuration. Busy or failed application remains saved and pending; confirmation requires the same loaded definition and selection identity after disposal. Existing session model/variant selections remain native.
